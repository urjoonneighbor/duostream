# Белый статический IP у провайдера

Зритель подключается к стримеру по адресу `ws://<IP>:8787`. Чтобы это работало, у стримера должен
быть **белый** (публичный, маршрутизируемый из интернета) IP-адрес, а лучше ещё и **статический**
(не меняется при переподключении), иначе адрес придётся каждый раз сообщать заново.

| Тип | Видно из интернета | Меняется | Подходит |
|---|---|---|---|
| Серый (за NAT/CGNAT провайдера) | нет | — | нет |
| Белый динамический | да | при переподключении или раз в сутки | да, но адрес придётся обновлять |
| Белый статический | да | нет | да, оптимально |

## 1. Проверить, какой IP сейчас

1. Посмотрите внешний (WAN) адрес в веб-интерфейсе роутера: «Состояние» / «Интернет» / «WAN IP».
2. Откройте с ПК сайт, показывающий ваш IP (например, 2ip.ru или ifconfig.me).
3. Сравните:
   - адреса **совпадают** — IP белый;
   - адреса **разные** или WAN-адрес из диапазонов `10.0.0.0–10.255.255.255`,
     `172.16.0.0–172.31.255.255`, `192.168.0.0–192.168.255.255`, `100.64.0.0–100.127.255.255` — IP серый
     (последний диапазон — CGNAT провайдера).

Дополнительно: `tracert -d 8.8.8.8` — если сразу за роутером идут хопы с адресами из этих
диапазонов, вы за NAT провайдера.

## 2. Подключить услугу

Почти у всех домашних провайдеров это отдельная услуга: «Статический IP-адрес», «Выделенный IP»,
«Фиксированный внешний адрес», «Белый IP». Обычно за неё взимается ежемесячная плата; цены и
условия уточняйте у своего провайдера.

1. Личный кабинет провайдера → «Услуги» / «Дополнительные услуги» → найдите услугу со статическим IP
   и подключите. Если её нет в списке — позвоните в поддержку и попросите «выделенный статический
   внешний IPv4-адрес для домашнего подключения».
2. Уточните у поддержки, как адрес выдаётся:
   - **автоматически** (DHCP или PPPoE выдают всегда один и тот же адрес) — менять в роутере ничего не нужно;
   - **вручную** — провайдер пришлёт IP, маску, шлюз и DNS. Впишите их в роутере: «Интернет» / «WAN» →
     тип подключения «Статический IP».
3. Если у провайдера своя приставка-роутер (ONT/модем) — попросите перевести её в режим моста (bridge),
   чтобы белый IP получал ваш роутер. Иначе пробрасывать порты придётся и на ней.
4. Перезагрузите роутер и повторите проверку из п. 1: WAN-адрес роутера должен совпасть с адресом на сайте.

Мобильный интернет (4G/5G-модемы) почти всегда за CGNAT; белый IP там подключают редко
и чаще только для юридических лиц.

## 3. После подключения

- Сообщите зрителю адрес вида `ws://203.0.113.10:8787` (ваш IP вместо примера) и пароль.
- Настройте проброс портов: [02-port-forwarding.md](02-port-forwarding.md).
- По желанию впишите белый IP в настройках приложения стримера «Сеть» → «Белый IP стримера».
  Без этого он определяется через STUN; поле нужно, если STUN-серверы недоступны.

## Если статический IP недоступен

- **Белый динамический IP + DDNS.** Многие роутеры умеют обновлять доменное имя при смене адреса
  (KeenDNS у Keenetic, встроенный DDNS у TP-Link и ASUS). Зритель подключается к
  `ws://<имя>:8787`. Это сторонний сервис имён, но через него идёт только DNS, не трафик.
- **Только серый IP у обоих.** Прямое соединение иногда всё равно устанавливается через STUN
  (если NAT провайдеров «мягкие»), но гарантии нет. Надёжный вариант — TURN на машине с белым IP:
  [04-optional-turn.md](04-optional-turn.md).
